# Authored content

Authored pack sources consumed by the command-line tool and tests without Godot: template vocabularies, authored pack allocation ledgers, and versioned numeric tables such as tier budgets, effort scores, and dealer spreads. Runtime assets for the game, such as UI, shaders, and materials, belong in `src/SpaceExplorer.Game/assets/` instead. See [decision 0009](../docs/decisions/0009-solution-layout.md).
