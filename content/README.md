# Authored content

Authored pack sources consumed by the command-line tool and tests without Godot: versioned template vocabularies, authored pack allocation ledgers, numeric tables such as tier budgets and effort scores, and source mesh/texture assets that generated primitives may select as content-addressed dependencies. Runtime-only presentation assets such as UI, approved shader implementations, and engine adapter resources belong in `src/SpaceExplorer.Game/assets/`; no Godot resource path is authoritative primitive data. See [decision 0009](../docs/decisions/0009-solution-layout.md) and [decision 0031](../docs/decisions/0031-primitive-complete-composition-and-storage.md).
