# Authored content

Authored pack sources consumed by the command-line tool and tests without Godot: the category registry record ([decision 0035](../docs/decisions/0035-category-registry-record-and-generator-revision-identifiers.md)), versioned template vocabularies, authored pack allocation ledgers, numeric tables such as tier budgets and effort scores, and source mesh/texture assets that generated primitives may select as content-addressed dependencies. Runtime-only presentation assets such as UI, approved shader implementations, and engine adapter resources belong in `src/SpaceExplorer.Game/assets/`; no Godot resource path is authoritative primitive data. `templates/basic/vocabulary.json` is the source form of the first vocabulary; the command-line tool reads it into the canonical record that is the authority ([decision 0042](../docs/decisions/0042-category-registry-revision-1-first-content-records-generator-and-publish-protocol.md)). A vocabulary is authored for one category-registry revision, since its templates are laid out by that revision's parameter schema, and this one is authored for the newest the build supports ([decision 0050](../docs/decisions/0050-registry-revision-2-grammar-version-2-and-versioned-record-growth.md)). See [decision 0009](../docs/decisions/0009-solution-layout.md) and [decision 0031](../docs/decisions/0031-primitive-complete-composition-and-storage.md).
